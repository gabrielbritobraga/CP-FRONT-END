# Portfólio — Gabriel Brito Braga

Landing page de portfólio com identidade editorial de revista: hero em tela cheia,
navegação numerada, lista de projetos em filetes, numerais vazados e rodapé em bloco coral.

Feita com HTML, CSS e JavaScript puros — sem framework e sem build.

## Estrutura

```
index.html      — página única (hero, sobre, skills, projetos, experiência, contato)
css/style.css   — identidade visual completa (Fraunces, Space Grotesk, JetBrains Mono, Inter)
js/main.js      — animações de reveal, parallax do hero, menu mobile
assets/         — fotos usadas no site
PROCESSO.md     — documentação do processo criativa com IA (Checkpoint 6: Vibecoding)
```

## Sobre o processo

Este site foi construído com auxílio de IA generativa (Qoder). Todo o processo —
referências visuais, decisões de identidade visual, prompts exatos e registro de
correções — está documentado em [PROCESSO.md](PROCESSO.md).
